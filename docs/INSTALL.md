# 安装说明

## macOS

1. 下载对应安装包：Apple Silicon 用 `DeepSeek-Harness-arm64.dmg`，Intel 用 `DeepSeek-Harness-x64.dmg`。
2. 打开 dmg，把 `DeepSeek Harness` 拖入 **Applications** 文件夹。
3. 首次打开：在「应用程序」中找到 DeepSeek Harness → **右键** → **打开** → 再次点击「打开」。

> 系统提示「无法验证开发者」是未公证应用的正常提示，可放心继续；仅首次需要右键打开，之后可正常双击启动。

## Windows

1. 下载 `DeepSeek-Harness-Setup-x64.exe`，双击运行。
2. SmartScreen 提示时点击「更多信息」→「仍要运行」。
3. 按向导完成安装，可选择开始菜单与桌面快捷方式。
4. 卸载：设置 → 应用 → DeepSeek Harness Desktop → 卸载。

## 数据位置

所有数据保存在本机，随时可备份或删除：

- macOS：`~/.dsh`
- Windows：`%USERPROFILE%\.dsh`

## 常见问题

**Q：打开后白屏或一直加载？** 稍等 2-3 秒即可；若超过 20 秒，关闭后重新打开。

**Q：更新提示？** 应用会自动检测官方 dsh 新版本，右下角出现提示后点击「重启安装」即可。
